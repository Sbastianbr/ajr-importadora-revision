# AJR Importadora — versión en revisión

Catálogo estático preparado para revisión de la propietaria. Fotografías, referencias, horarios, tallas, precios y disponibilidad requieren validación comercial. Esta copia no representa un lanzamiento definitivo.

La web está en `site/`, sin compilación ni dependencias. Todos los recursos locales utilizan rutas relativas, compatibles con un sitio de proyecto de GitHub Pages. El aviso de revisión aparece en el footer. `noindex` solicita que no se indexe; no ofrece privacidad ni control de acceso.

## Contenido de la revisión

La copia incluye únicamente la web y sus recursos necesarios. No contiene informes de auditoría, capturas, material original de trabajo, archivos privados ni fixtures de pruebas.

## Publicación manual en GitHub Pages

La publicación pública de esta versión de revisión está autorizada. Esto no sustituye la validación comercial de la propietaria ni representa un lanzamiento definitivo.

En Settings → Pages se utiliza GitHub Actions. El workflow no se ejecuta al hacer push: se activa manualmente con su casilla de confirmación. Publica únicamente `site/`. La URL activa se consulta en Settings → Pages o en el resultado del despliegue.

No se configura dominio propio. Antes de compartir una URL se debe comprobar el despliegue y su apertura real en computador y móvil.
